# King Jesus Bible Project

The King James text here (kingjamesbible.osis.xml) is the base for the [King Jesus Bible](http://akaitsurugi.org/library/bibles/king_jesus_bible), but it is also used as the source to generate the [King James Bible](http://akaitsurugi.org/library/bibles/king_james_bible) on Akai Tsurugi.
